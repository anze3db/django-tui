# Changelog

django-tui uses [calendar versioning](https://calver.org/): `YY.N` is the Nth release of
the year (`26.1`, `26.2`, … `27.1`). Each section lists the merged pull requests by
category (or the commits, for changes pushed straight to `main`), plus everyone who
contributed to that release.

Notes under **Unreleased** are written by hand and become the "Highlights" of the
next release. Everything else is generated by `scripts/release.py` when a release is
prepared (see [RELEASING.md](https://github.com/anze3db/django-tui/blob/main/RELEASING.md)).

## Unreleased

- **A new command screen.** Type a command and its arguments at the `$ python manage.py`
  prompt, like in your shell. The command name filters the list of commands, and the
  arguments fill in the form below, which updates the command in turn. Press enter to run
  it, or tab to edit its options first. Options shared by all commands are tucked away.
- **Commands run inside the TUI** and come back to it when they finish, instead of
  exiting and starting Django again for every command. Interactive commands like `shell`,
  `createsuperuser` and `runserver` work as before.
- **Much faster**, especially when holding down an arrow key in the command list.
- **The shell** shows the value of the last expression like the Python REPL, runs the
  selection (or everything if nothing is selected), keeps names defined in earlier runs,
  and starts tracebacks at your code.
- Press ctrl+c twice to quit.
- Fixed: the TUI was unresponsive on macOS, with keys showing up as `^[[B`, when a
  management command imports `readline` ([#8](https://github.com/anze3db/django-tui/issues/8)).
- Fixed: importing every management command no longer affects the commands you run. For
  example, django-debug-toolbar's `debugsqlshell` made every command print its SQL.
- Fixed: `python manage.py ish` no longer shows up as a broken command, and commands run
  with the same Python as the TUI.
- Python 3.11 to 3.15 and Django 5.2, 6.0 and 6.1 are supported. Dropped Python 3.8 to 3.10,
  Django 3.2 to 5.1, and the Trogon and Click dependencies.
